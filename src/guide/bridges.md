Bridges: extending a bus over a byte transport (feature `bridge`).

```toml
nattes = { version = "0.4", features = ["bridge"] }
```

The feature adds [`Bridge`](crate::Bridge), [`Codec`](crate::Codec), and a
[`Wire<C>`](crate::Wire) implementation on every topic generated by
[`topics!`](crate::topics).

A `Bridge` extends a channel of a bus over a byte transport to the same channel
of another bus, in another process or on another machine. A subscription on
either side gets the messages published on both:

```no_run
# use futures::StreamExt;
# use nattes::{topics, Bridge, Channel, Codec, CodecError};
# pub struct GitPushMsg { pub branch: String }
# topics! { topics { git { push: GitPushMsg } } }
// One implementation per message and parameter type,
// or a generic one over serde (see `Codec`).
struct Utf8;

impl Codec<GitPushMsg> for Utf8 {
    fn encode(&self, msg: &GitPushMsg, out: &mut Vec<u8>) -> Result<(), CodecError> {
        out.extend_from_slice(msg.branch.as_bytes());
        Ok(())
    }
    fn decode(&self, bytes: &[u8]) -> Result<GitPushMsg, CodecError> {
        Ok(GitPushMsg { branch: String::from_utf8(bytes.to_vec())? })
    }
}

# #[tokio::main]
# async fn main() -> Result<(), Box<dyn std::error::Error>> {
# let bus = Channel::<topics::Topic>::new();
use tokio_util::codec::{Framed, LengthDelimitedCodec};

let socket = tokio::net::UnixStream::connect("/run/app.sock").await?;
let (sink, stream) = Framed::new(socket, LengthDelimitedCodec::new()).split();
Bridge::new(bus.clone(), Utf8).run(sink, stream).await?;
# Ok(())
# }
```

- **Bring your transport and codec.** [`run`](crate::Bridge::run) takes any
  `futures` `Sink<Bytes>` and `Stream` of frames, so framing, reconnection,
  encryption and compression come from other crates. Messages and parameters
  are encoded by your [`Codec`](crate::Codec), typically one generic
  implementation over serde.
- **Only what's wanted crosses.** Each side tells the other the patterns of its
  subscriptions, and sends a message only if the other side subscribes to it,
  once, however many subscribers it has there. Fixed parameters widen to `*`
  across the bridge; the receiving side's trie keeps the right values. Local
  delivery never serializes anything.
- **Versions.** Both sides exchange a frame format version
  ([`FRAME_VERSION`](crate::FRAME_VERSION)), the only thing that can refuse a
  connection. Topics are identified by a hash of their name, not their
  position, so adding or reordering topics changes nothing. A topic only one
  side has is never asked for by the other; a message whose topic is unknown or
  whose payload doesn't decode is dropped and counted in
  [`bridge.dropped()`](crate::Bridge::dropped). Evolve messages within what
  your codec tolerates, or under a new topic name.
- **Topology.** Messages received from a bridge are never sent on to another
  bridge, like NATS routes: connect every pair of buses (a full mesh).
- **Relative paths.** A bridge on `bus.user()` carries `user` and what's below
  it, and each side can mount the shared tree anywhere.
- **Limits.** Delivery stays at most once. Only messages cross: requests reach
  the other side's subscribers but not its responders.
- **Backpressure.** The messages for the other side wait in a buffer of their
  own, [`.buffer(n)`](crate::Bridge::buffer) with
  [`.on_full(…)`](crate::Bridge::on_full) like a subscription, defaulting to
  the bridged topic's
  [delivery defaults](crate::guide::declaring#delivery-defaults):
  `Overflow::Wait` makes local publishers wait for the transport.

The codec must handle every message and parameter type of the bridged tree, or
the bridge doesn't compile:

```compile_fail,E0277
# use nattes::{topics, Bridge, Channel, Codec, CodecError};
# pub struct GitPushMsg;
# pub struct GitTagMsg;
# topics! { topics { git { push: GitPushMsg, tag: GitTagMsg } } }
# struct MyCodec;
# impl Codec<GitPushMsg> for MyCodec {
#     fn encode(&self, _: &GitPushMsg, _: &mut Vec<u8>) -> Result<(), CodecError> { Ok(()) }
#     fn decode(&self, _: &[u8]) -> Result<GitPushMsg, CodecError> { Ok(GitPushMsg) }
# }
# fn main() {
# let bus = Channel::<topics::Topic>::new();
Bridge::new(bus, MyCodec);
// error: the trait bound `MyCodec: Codec<GitTagMsg>` is not satisfied
# }
```
